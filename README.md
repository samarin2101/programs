# Скрипт для автоматической установки программ на Arch Linux

Этот скрипт предназначен для удобной установки набора полезных программ на Arch Linux. Он автоматически настроит систему, установит необходимые приложения, а также настроит Docker, Fish и OpenSSH.

## Как использовать

1. Клонируйте или скачайте репозиторий.
2. Сделайте файл скрипта `programs.sh` исполняемым:
   ```bash
   chmod +x programs.sh
   ```
3. Запустите скрипт:
   ```bash
   ./programs.sh
   ```
4. Следуйте инструкциям на экране, чтобы завершить установку и настройку.

## Как добавить собственные программы

Чтобы добавить дополнительные программы для установки, отредактируйте переменную `PACKAGES` в скрипте, добавив нужные пакеты в следующем формате:
```bash
PACKAGES+=("название_пакета")
```

## Стандартный набор программ

Скрипт включает в себя установку следующих приложений:

- `nodejs`, `npm` — для работы с JavaScript.
- `ark`, `unrar` — для работы с архивами.
- `fish` — консольная оболочка.
- `openssh` — для удалённого доступа.
- `haruna` — видеоплеер.
- `neofetch`, `screenfetch` — утилиты для отображения информации о системе.
- `qbittorrent`, `telegram-desktop`, `audacity`, `kate`, `vim`, `gimp` — полезные программы для повседневного использования.
- `btrfs-progs`, `gnome-disk-utility` — утилиты для работы с файловыми системами и дисками.

## Требования

- Arch Linux или производные.
- Права `sudo` для установки пакетов и настройки сервисов.

## Важные замечания

- Для корректного применения всех изменений рекомендуется перезагрузить систему после установки всех программ, особенно если вы устанавливаете их на чистую систему.
