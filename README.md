# Скрипт для установки программ на Arch Linux

Этот скрипт автоматически устанавливает набор программ на Arch Linux и настраивает систему. Он включает в себя установку популярных приложений, а также настройку Docker, Fish и OpenSSH.

## Как использовать

1. Скачайте или клонируйте репозиторий.
2. Дважды щелкните на файл скрипта `programs.sh` для его запуска.
   - Если по каким-либо причинам скрипт не запускается, сделайте его исполняемым, выполнив команду:
     chmod +x programs.sh
3. После этого снова дважды щелкните на файл скрипта или запустите его из терминала:
    ./programs.sh
4. Следуйте инструкциям на экране для установки программ и настройки системы.

## Как добавить свои программы

Чтобы добавить свои программы для установки, отредактируйте переменную `PACKAGES` в скрипте, добавив нужные пакеты в формате `PACKAGES+=("название_пакета")`.

## Программы по умолчанию

Скрипт устанавливает следующие программы:

- `nodejs`, `npm` — для работы с JavaScript.
- `ark`, `unrar` — для работы с архивами.
- `fish` — консульная альтернативная оболочка.
- `openssh` — для удалённого доступа.
- `haruna`, видеоплеер
- `neofetch`, `screenfetch` — утилиты для отображения информации о системе.
- `qbittorrent`, `telegram-desktop`, `audacity`, `kate`, `vim`, `gimp` — программы для повседневного использования.
- `btrfs-progs`, `gnome-disk-utility` — для работы с файловыми системами и дисками.

## Требования

- Arch Linux или производный.
- Права `sudo` для установки пакетов и настройки сервисов.
